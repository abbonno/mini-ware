# Implementación de framework de creación de minijuegos
TFG

Tutor: Pablo García Sánchez

El objetivo de este proyecto será desarrollar un framework que permita crear juegos cortos o minijuegos. Estos juegos tienen un objetivo y unas reglas sencillos, así como una corta duración, buscando un juego rápido y asequible para cualquier público.

El framework a desarrollar permitirá la modificación de ciertos aspectos como los controles, las programación de reglas, las visuales y el audio del minijuego. Además, ofrecerá una interfaz para visualizar y probar los mismos.

Durante su desarrollo se pretenden usar, al menos, las siguentes tecnologías: godot y su lenguaje de programación GDScript para la programación básica de la interfaz y el marco de desarrollo de minijuegos, git para llevar a cabo un control de versiones y del trabajo diario y [diagrams.net](http://diagrams.net/) para tratar el desarrollo del software. Así mismo, se seguirá una metodología de desarollo ágil basada en Kanban, para ello he decidido emplear Trello. Finalmente, se desarrollarán varios juegos para validarlo.

*RESUMEN*
MiniWare es un framework de creación de videojuegos basados en minijuegos o microjuegos. Está específicamente desarrollado para dar vida a juegos que recopilen varios de ellos en niveles que superar al estilo de WarioWare: Touched!. La principal motivación tras este proyecto es captar de forma fiel los aspectos de diseño de este tipo de juegos y aportar a los desarrolladores de videojuegos una estructura inicial con estas características con la que hacer el suyo. Esto se consigue mediante la creación de una plantilla en la que podrán personalizar el estilo e integrar sus propios minijuegos con facilidad y flexibilidad, bajo un flujo de juego predesignado. La licencia es de código abierto, totalmente libre de uso para cualquier proyecto.

*ABSTRACT*
MiniWare is a framework for creating video games based on minigames or microgames. It is specifically developed to bring to life games that compile several of these short challenges into levels to be completed, following the style of WarioWare: Touched!. The main motivation behind this project is to faithfully capture the design aspects of this type of game and provide game developers with an initial structure featuring these characteristics to build their own. This is achieved through the creation of a template in which they can easily and flexibly customize the style and integrate their own minigames within a predefined game flow. The license is open source, totally free To create any type of project.
